# Value rubric

Score 0–5 per dimension. Store scores in the run; never in the published note.

| Dimension | Question | 0 | 3 | 5 |
|---|---|---|---|---|
| **Goal alignment** | Does this serve a specific Intent Map ambition/belief, and a `charter.md` operating priority? | unrelated or generic | supports a clause | moves a priority materially |
| **Personal grounding** | Is it built on a specific Work Map record plus verified live evidence? | could be anyone | names a real project | cites the record, artifact, and constraint |
| **Novelty** | Does it add a fact, pattern, contradiction, or connection you has not already stated? | restates the maps | new framing | new fact that changes how he thinks or decides |
| **Leverage** | Given limited discretionary time, could one implication matter? | cosmetic or task-generating | marginal improvement | changes the next 30 days with one clear implication |
| **Evidence & actionability** | Are observed facts separated from interpretation and hypothesis? | opinion or speculation | one source, vague implication | primary sources, artifact evidence, and a named implication |

## Gate

- total ≥ **20 / 25**
- no dimension < **3**
- grounding ≥ **4**
- novelty ≥ **3**
- not a substantive duplicate of a recent note or an unresolved recommendation
- survives the adversarial pass in Stage 4

## Automatic fails

- A Work Map summary or inventory tour presented as an insight.
- A restatement of your stated goals without a new fact, pattern, contradiction, or connection.
- A recommendation for a capability the Work Map documents as already implemented, unless the evidence shows a
  specific failure in that implementation.
- Generic best-practice advice that could have been written without your projects.
- A speculative opportunity with no artifact, observation, or measurable evidence.
- A task list whose main output is work for you.

Thresholds live here; changing them does not require touching the loop.

## The 10,000-users test

> Could this note have been written for 10,000 other OpenClaw users without knowing anything about you,
> his Intent Map, or his Work Map?

If yes → it fails. A generic note is a topic; a strategist note is a *situation*.

## The usefulness test

Would this change a decision, reveal an opportunity, expose a contradiction, inspire a concrete experiment,
or save meaningful effort? If not, do not publish it. The output should be primarily a **new understanding
plus one implication**, not homework. Scoring screens candidates; judgment decides. Zero notes is a valid week.
