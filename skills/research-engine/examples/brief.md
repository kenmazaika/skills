# Example brief (structure only — subject is a sample)

## Question

Among open-source AI-agent projects aimed at individual developers, what share of GitHub stars
corresponds to real use, and which observable repository characteristics distinguish projects that
produce actual users from projects that produce attention only?

## Definitions and scope

- **Population.** Public GitHub repositories in the "personal agent / agent harness / coding-agent
  tooling" family: software a developer installs and runs themselves to delegate work to an LLM-backed
  agent (CLI agents, self-hosted personal assistants, agent harnesses, agent frameworks with a
  runnable local component). Repositories created or first made public between 2025-05 and 2026-11
  and holding **at least 500 GitHub stars** at the time of measurement.
- **Attention** = stars, watchers, and social mentions.
- **Use** = any of the following observable proxies, measured separately rather than collapsed into
  one score: package-registry downloads (npm / PyPI / crates.io) where the project publishes a
